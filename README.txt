Swarup Sir's Knowledge Hub — Separate Mock Test Module

This package keeps Mock Tests separate from the normal Assignment module.

Teacher Dashboard:
- Mock Test Management is a separate option.
- Four Mock Test question-bank sections: MAT, EVS, Arithmetic, Language.
- Question banks can contain the required sub-parts/passage groups.
- Generate an independent 80-question, 100-mark, 2-hour Mock Test.
- Assign Mock Tests to multiple classes or selected students.
- Mock Test Results are separate from Assignment Results.

Assignments:
- New Assignment contains only Video + MCQ and MCQ Only.
- Mock Test is no longer an Assignment Type.

Student Dashboard:
- Mock Tests appear in a separate Mock Tests area.
- Mock Test attempts/results are separate from normal assignments.

Database:
1. Run the existing assignment/teacher/student SQL migrations as needed.
2. Run mock_question_bank_migration.sql in Supabase SQL Editor.

Deployment:
- Upload the package contents to Cloudflare Pages.
- main.html is the primary application file.
