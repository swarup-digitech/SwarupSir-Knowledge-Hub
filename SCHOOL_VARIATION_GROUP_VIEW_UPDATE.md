# School Question Bank — Variation Group View Update

Implemented for **School Course only**. JNVST Question Bank logic is unchanged.

## Added
- Variation Group filter in School Question Bank.
- Variation Group values show the number of question records in each group.
- Variation Group in the question table is clickable.
- Clicking a group opens a modal showing all questions in that group.
- English and Assamese question text are displayed side-by-side.
- Question metadata (ID, type, marks, chapter/topic) is shown.
- Question images are shown when available.
- MathJax rendering is applied to the group view.
- Each group member has Edit and Generate Similar Question actions.

## Usage
1. Open School Course → Question Bank.
2. Use **Variation Group** filter to select a group, or click a group code in the table.
3. Review all variations together.
4. Use **Edit** or **Generate Similar Question** from the group view.
