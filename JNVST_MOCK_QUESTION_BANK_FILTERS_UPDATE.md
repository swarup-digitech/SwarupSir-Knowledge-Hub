# JNVST Mock Question Bank Filters Update

Integrated into the latest complete project ZIP.

## Manage Mock Question Bank
Teachers can now filter the mock question bank by:
- Medium: Assamese, English, Common (MAT)
- Part / Question Bank: MAT, EVS, Arithmetic, Language and configured sub-parts
- Topic: populated from existing question records
- Passage: populated from existing passage titles/IDs
- Status: Active Only, All Questions, Inactive Only
- Search: question text, options, topic, passage, part and language

The page shows `Showing X of Y question(s)` and keeps availability/set validation based on the complete active bank, not the filtered subset.

Filtering is view-only and does not modify question-bank data. Existing Edit, Activate/Deactivate, Delete, Bulk Upload and Generate Test actions are preserved.
